# Security and privacy reports

Please do not put Bluetooth addresses, serial numbers, raw protocol logs, or exploit details in a public issue.

If GitHub's private vulnerability reporting is enabled for this repository, use **Security → Report a vulnerability**. Otherwise, open a public issue with only a short, non-sensitive description and ask the maintainer for a private contact method. Do not attach sensitive data to that issue.

For ordinary bugs, use the bug report template and redact any exported logs before posting.
